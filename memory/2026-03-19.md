## 💡 Lessons Learned

1. **定时任务配置**
   - 使用 `openclaw cron add` 创建任务
   - 使用 `openclaw cron edit` 修改任务
   - 使用 `openclaw cron run <id>` 手动测试
   - main session 任务需要 `--system-event` 参数

2. **飞书集成**
   - feishu_doc 工具在子agent中调用不稳定
   - 直接发送到飞书聊天更可靠
   - 飞书文档 token 从 URL 提取：`/docx/XXX` → `doc_token = XXX`

3. **新闻源可靠性**
   - AP News: ✅ 可抓取
   - CNBC: ✅ 可抓取
   - BBC/Reuters/Bloomberg/Guardian: ❌ 反爬保护
