# Heartbeat定时任务系统

## 问题诊断

**问题**: 定时任务没有在预期时间（8:30）自动执行

**根本原因**:
- Heartbeat机制需要外部定期触发（每30分钟发送检查消息）
- 之前没有配置自动触发机制
- Cron任务配置有困难（权限/环境问题）

## 解决方案

✅ **已实施**: Python守护进程替代cron

### 1. Heartbeat守护进程

**文件**: `scripts/heartbeat_daemon.py`

**功能**:
- 每30分钟自动检查
- 在8:30-9:00时间窗口自动执行A股投资分析
- 每天只执行一次（避免重复）
- 完整日志记录

**启动方法**:
```bash
bash scripts/start_heartbeat_daemon.sh
```

**停止方法**:
```bash
pkill -f heartbeat_daemon.py
```

**查看日志**:
```bash
tail -f /tmp/heartbeat_daemon.log
```

## 系统架构

```
Heartbeat守护进程（Python）
    ↓ 每30分钟检查
    ↓ 
检查当前时间是否在8:30-9:00？
    ↓ 是（且今天未执行）
    ↓
执行 run_integrated_system.py
    ↓
生成每日投资建议
    ↓
记录到日志
```

## 优势

1. **不依赖cron**: 避免环境/权限问题
2. **独立进程**: 不影响OpenClaw主进程
3. **完整日志**: 便于调试和监控
4. **自动去重**: 每天只执行一次
5. **容错机制**: 异常自动恢复
