# 中国股票指数数据源解决方案

## 问题
Yahoo Finance API 对 GitHub Actions IP 限流，导致中国相关指数（上证、深证、恒生）频繁获取失败。

## 解决方案：新浪财经 API

### API 端点
```
https://hq.sinajs.cn/list=sh000001,sz399001,hkHSI
```

### 请求要求
- 必须添加 Header: `Referer: https://finance.sina.com.cn`
- 返回编码: GBK（需要转换为 UTF-8）
- 完全免费，无 API Key 限制

### 数据格式示例

**上证指数 (sh000001)**
```
上证指数,3892.2690,3881.2797,3920.9048,3929.5997,3891.8159,...
字段: 名称,开盘,昨收,当前,最高,最低,...
```

**深证成指 (sz399001)**
```
深证成指,13669.053,13536.556,13785.140,13835.031,13666.842,...
```

**恒生指数 (hkHSI)**
```
HSI,恒生指数,25280.520,25063.711,25390.300,25193.650,25207.490,143.779,0.574,...
字段: 代码,名称,当前,昨收,最高,最低,开盘,涨跌点数,涨跌幅,...
```

### 测试结果
- ✅ 上证指数: 3920.90 (+1.02%)
- ✅ 深证成指: 13785.14 (+1.84%)
- ✅ 恒生指数: 25207.49 (+0.57%)

### 优势
1. **稳定性高** - 新浪财经是中国主要财经数据提供商
2. **无限制** - 不需要 API Key，没有请求频率限制
3. **速度快** - 国内CDN，响应时间 <100ms
4. **数据实时** - 交易时段实时更新

### 实施计划
修改 `.github/workflows/update-data.yml`，对中美欧日使用不同数据源：
- 中国指数 → 新浪财经 API
- 美欧日指数 → Yahoo Finance API (保留现有逻辑)
