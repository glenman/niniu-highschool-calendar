### 关键技术突破

#### 1. Matchweek提取逻辑 ⭐
**发现**: 必须从FBref页面提取实际matchweek值，**绝对不能使用循环变量**

**错误做法**:
```python
for i, match in enumerate(matches, 1):
    filename = f"{date}-中超-第{i}轮.json"  # ❌ 使用循环变量
```

**正确做法**:
```javascript
// 从页面提取
const matchweekMatch = bodyText.match(/Matchweek\s+(\d+)/i);
if (matchweekMatch) result.matchweek = matchweekMatch[1];
```

**原因**: 补赛等特殊情况时，比赛日期与轮次不一致

**实际案例**: 2025赛季第6轮补赛
- 原定日期: 2025-04-16
- 实际日期: 2025-06-18
- 正确文件名: `2025-06-18-中超-第6轮.json`
