# Heartbeat 执行说明

## 每日荐股分析任务

**执行时间**：每日8:30-9:00

**执行步骤**：

### 1. 运行整合版系统
```bash
cd /Users/glenman/.openclaw/workspace
python3 investment-system/run_integrated_system.py
```

### 2. 生成报告
系统会自动生成：
- `memory/investment/daily/integrated_advice_YYYY-MM-DD.md`（整合版建议）
- `memory/investment/daily/screened_stocks_YYYY-MM-DD.csv`（筛选结果）

### 3. 推送到飞书群 ⭐
生成报告后，**必须**将报告内容发送到飞书群。

**操作**：
1. 读取 `integrated_advice_*.md` 文件
2. 直接输出报告内容（不是文件路径）
3. 内容会自动发送到群

**示例**：
```
================================================================================
🎯 整合版开盘前操盘建议 - 2026-04-01
================================================================================

⏰ 生成时间: 2026-04-01 08:30:15
📊 数据来源: 历史知识库 + 今日新闻 + 反馈学习

## 📚 历史知识分析
- 历史准确率: XX%
- 情绪趋势: improving/stable/declining
- 预测置信度: XX%

## 📰 今日关键新闻
1. [财联社] 新闻标题...
2. ...

## 💡 智能推荐股票（结合历史模式）
1. **代码 名称** - 调整评分:X.X 置信度:XX% 风险:level
2. ...

## 🎯 操作建议（基于置信度）
- 建议仓位: XX-XX%
- 置信度: 高/中/低
- 策略: 积极/谨慎/观望

## ⚠️ 风险提示
- 本建议基于AI分析和历史模式
- 历史表现不代表未来收益
- 请独立决策，控制风险
```
