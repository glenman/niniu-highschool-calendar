## 🔧 知识库建设

### 1. 新闻归档

**分类方式**：
- **宏观**（macro）：央行、GDP、CPI、利率、货币政策
- **政策**（policy）：国务院、发改委、监管、改革
- **行业**（industry）：板块、产业链、供需、产能
- **市场**（market）：指数、涨跌、资金、北向
- **公司**（company）：业绩、财报、盈利、亏损

**归档流程**：
```
新闻采集 → 智能分类 → 情感分析 → 关键词提取 → 按主题归档
```

**存储格式**：
```json
{
  "title": "三大指数均涨超1%，医药板块持续爆发",
  "source": "财联社",
  "category": "market",
  "sentiment": "positive",
  "keywords": ["医药", "涨停", "科技"],
  "archived_at": "2026-04-01 09:00:00"
}
```

### 2. 趋势追踪

**追踪维度**：
- **情绪得分**：-1到+1（基于新闻情感）
- **热门主题**：按关键词频率排序
- **板块轮动**：资金流向分析

**数据结构**：
```json
{
  "2026-04-01": {
    "news_count": 49,
    "sentiment_score": 0.08,
    "hot_topics": [
      ["医药", 15],
      ["科技", 12],
      ["新能源", 8]
    ]
  }
}
```

### 3. 反馈历史

**验证逻辑**：
- 获取昨日推荐股票
- 获取今日实际涨跌幅
- 涨幅>3%视为成功
- 计算准确率

**数据结构**：
```json
{
  "2026-04-01": {
    "predictions": [
      {
        "stock": "300149",
        "predicted": "上涨",
        "actual": "+5.2%",
        "success": true
      }
    ],
    "accuracy": 0.75
  }
}
```

## 🤖 模型设计

### 1. 新闻分析模型

**分类模型**：
- 基于关键词规则
- 5大类别自动分类
- 自动归档到对应目录

**情感模型**：
- 关键词匹配
- 3级情感（positive/negative/neutral）
- 量化评分（-1到+1）

**关键词提取**：
- 停用词过滤
- 频率统计
- Top 5关键词

### 2. 股票筛选模型

**多因子筛选**：
```
1. 过滤ST股票
2. 过滤停牌（涨跌幅=0）
3. 过滤极端波动（涨跌幅>10%）
4. PE筛选（5-100倍）
5. 换手率筛选（0.01%-50%）
6. 综合评分排序
```

**评分模型**：
```
基础评分 = 涨跌幅(40%) + 换手率(30%) + PE(30%)

调整评分 = 基础评分 + 情绪趋势调整
```

### 3. 置信度模型

**动态调整**：
```
if 历史准确率 >= 70%:
    置信度 = min(准确率, 85%)
    风险等级 = low
    建议仓位 = 60-70%

elif 历史准确率 >= 50%:
    置信度 = 准确率
    风险等级 = medium
    建议仓位 = 40-50%

else:
    置信度 = 准确率
    风险等级 = high
    建议仓位 = 20-30%
```

### 4. 反馈学习模型

**验证流程**：
```
1. 加载昨日预测
2. 获取今日实际涨跌幅
3. 计算准确率（涨幅>3%视为成功）
4. 分析成功预测的特征
5. 生成优化建议
```

## ⚠️ 风险提示

### 系统风险

1. **数据源限制**
   - 东方财富API限制（每次最多3000只）
   - 海外新闻采集不稳定
   - 非交易日数据延迟

2. **模型局限**
   - 基于历史数据，无法预测黑天鹅
   - AI分析有局限性
   - 需要7天建立有效反馈

3. **准确率不确定**
   - 初期置信度低（50%）
   - 历史准确率不代表未来

### 投资风险

⚠️ **重要声明**：

- **所有建议仅供参考，不构成投资建议**
- **市场有风险，投资需谨慎**
- **请独立决策，严格控制风险**
- **历史表现不代表未来收益**
