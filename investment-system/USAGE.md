# A股投资分析系统 - 使用指南

## 🦞 系统简介

小龙虾AI投资分析系统，基于免费数据源（东方财富API），提供：
- **每日自动筛选优质股票**
- **多因子综合评分模型**
- **市场数据跟踪**（北向资金等）
- **学习记录系统**

## ⚡ 快速开始

### 手动运行
```bash
cd /Users/glenman/.openclaw/workspace
python3 investment-system/run_daily_analysis.py
```

或使用快捷脚本：
```bash
./investment-system/quick_run.sh
```

### 自动运行
系统已配置到HEARTBEAT.md，每日早上9:00-9:30自动执行。

## 📊 输出文件

每日生成3个文件（位于`memory/investment/daily/`）：

1. **筛选结果**: `screened_stocks_YYYY-MM-DD.csv`
   - 包含所有筛选出的股票数据
   
2. **分析报告**: `daily_report_YYYY-MM-DD.md`
   - Markdown格式的完整报告
   - 包含TOP10推荐股票
   - 包含市场概况和筛选说明

3. **学习记录**: `learning_YYYY-MM-DD.md`
   - 每日市场观察
   - 待学习主题

## 🔍 筛选模型说明

### 多因子筛选流程
1. **基本面筛选**
   - PE（市盈率）：5-100倍
   - 排除ST和退市股票

2. **技术面筛选**
   - 换手率：0.01%-50%
   - 排除停牌股票
   - 排除极端波动（涨跌幅>10%）

3. **综合评分模型**
   - 涨跌幅权重：40%（适度上涨得分高）
   - 换手率权重：30%（3%左右最优）
   - 市盈率权重：30%（20倍左右最优）

## 📈 当前限制

1. **数据源**
   - 仅使用东方财富免费API
   - 每次获取约100只股票（API限制）
   - 北向资金数据接口不稳定

2. **分析能力**
   - 基于公开数据，无实时深度数据
   - AI分析有局限性
   - 不包含基本面深度分析（财务报表、研报等）

3. **时间限制**
   - 非交易日数据可能为空或为上一交易日数据
   - 周末/节假日不产生新数据
