# 投资知识库系统 - 架构设计

## 目标

构建一个**自我学习、自我进化**的投资分析系统，通过长期积累知识发现投资规律。

---

## 系统架构

### 1. 知识库层（Knowledge Base）

```
memory/investment/knowledge/
├── news_archive/              # 新闻归档（按日期+主题）
│   ├── 2026-04/
│   │   ├── macro/            # 宏观经济
│   │   ├── industry/         # 行业动态
│   │   ├── policy/           # 政策解读
│   │   └── market/           # 市场情绪
├── reports_archive/           # 研报归档
│   ├── 2026-04/
│   │   ├── industry/         # 行业研报
│   │   ├── company/          # 个股研报
│   │   └── strategy/         # 策略研报
├── stock_analysis/            # 个股研究
│   ├── 300149_睿智医药.md
│   ├── 301392_汇成真空.md
│   └── ...
├── industry_analysis/         # 行业研究
│   ├── 医药行业.md
│   ├── 新能源.md
│   └── ...
├── trends/                    # 趋势研究
│   ├── sector_rotation.md    # 板块轮动
│   ├── capital_flow.md       # 资金流向
│   └── market_sentiment.md   # 市场情绪
└── patterns/                  # 模式识别
    ├── breakout_patterns.md  # 突破形态
    ├── reversal_patterns.md  # 反转形态
    └── accumulation.md       # 吸筹模式
```

### 2. 分析引擎（Analysis Engine）

#### 2.1 新闻分析器
- **主题分类**：自动识别新闻主题（宏观/行业/政策/市场）
- **情感分析**：提取新闻情绪（利好/利空/中性）
- **关联分析**：关联股票、行业、板块
- **时效性标记**：短期影响/中长期影响

#### 2.2 研报分析器
- **观点提取**：核心观点、逻辑、数据
- **评级跟踪**：买入/增持/中性/减持
- **目标价记录**：目标价格区间
- **逻辑验证**：后续验证研报逻辑

#### 2.3 趋势分析器
- **板块轮动**：识别资金在不同板块间的流动
- **情绪指标**：市场情绪量化指标
- **周期分析**：行业周期、市场周期
- **相关性分析**：不同资产/板块相关性

#### 2.4 模式识别器
- **历史模式**：识别历史相似市场环境
- **形态识别**：技术形态自动识别
- **资金模式**：主力资金行为模式
- **事件驱动**：重大事件对市场的影响模式

## 数据流

```
[新闻/研报] → [采集] → [分类] → [分析] → [存储]
                                          ↓
[趋势分析] ← [模式识别] ← [关联分析] ← [知识库]
     ↓
[策略优化] → [推荐模型] → [每日选股]
```

## 学习机制

### 每日学习（自动）
1. **采集**：新闻、研报、行情
2. **分类**：自动分类到对应主题
3. **分析**：提取关键信息、情绪、关联
4. **存储**：归档到知识库
5. **更新**：更新趋势指标、模式库

### 每周复盘（自动）
1. **验证**：验证本周判断的准确性
2. **总结**：总结本周市场特征
3. **调整**：调整筛选参数、权重

### 每月深度学习（自动）
1. **趋势研究**：分析月度趋势变化
2. **模式发现**：发现新的投资模式
3. **策略优化**：优化投资策略
4. **知识整合**：整合碎片化知识

## 核心模块

### 模块1：智能分类器
```python
- 输入：新闻/研报标题+内容
- 输出：主题分类、情绪标签、关联股票
- 方法：关键词+规则+GLM-5分析
```

### 模块2：趋势追踪器
```python
- 输入：历史数据、实时数据
- 输出：趋势指标、异常信号
- 方法：时间序列分析、统计模型
```

### 模块3：模式匹配器
```python
- 输入：当前市场状态
- 输出：历史相似场景、后续走势
- 方法：相似度计算、模式库检索
```

### 模块4：策略优化器
```python
- 输入：历史推荐、实际表现
- 输出：调整后的策略参数
- 方法：反馈学习、参数调优
```
