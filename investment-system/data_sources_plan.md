## 📝 实现方式

### 新闻采集
- **方式**: Python + urllib + web_fetch
- **频率**: 每日早上8:00-9:00采集
- **存储**: `memory/investment/daily/news_YYYY-MM-DD.json`
- **分析**: 提取标题、摘要、关键词、情绪

### 研报采集
- **方式**: web_fetch研报列表页
- **频率**: 每日早上8:00-9:00采集最新研报
- **存储**: `memory/investment/daily/reports_YYYY-MM-DD.json`
- **分析**: 提取研报标题、摘要、评级、目标价
